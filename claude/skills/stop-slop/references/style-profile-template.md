# Author style profile (template)

Fill this in on request ("calibrate to my style") from 3-5 texts the author
wrote without AI help, 2,000+ words total. Save the completed copy as
`references/style-profile.md` next to this template. Until that file
exists, the skill runs on the defaults in SKILL.md and phrases.md/
structures.md.

Rules for filling it in:

- Every entry must be backed by an observation from the samples, not a
  guess. No observation: leave the entry empty, the default stands.
- The profile describes how the author actually writes, rough edges
  included. The rough edges are the signature — don't smooth them out.
- The profile cannot: enable invented specifics (see epistemics.md), or
  request imitation of another named author.
- Editable by hand. On "learn from this text too," append new
  observations rather than rewriting; conflicts resolve in favor of the
  fresher sample, with a dated note.
